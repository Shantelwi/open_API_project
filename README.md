⭐ Star Wars Open API Project
📖 Overview

This project is a simple website that displays information from the Star Wars universe using a public API. The site allows users to view characters, starships, and movies from the Star Wars franchise.

The data is fetched from the Star Wars API (SWAPI) and displayed dynamically using JavaScript.

This project was built to practice working with APIs, JavaScript, and DOM manipulation.

🚀 Features

View a list of Star Wars characters

Click a character to see more information

Collapsible cards that show:

Gender

Birth year

Homeworld

Movies the character appears in

View a list of Starships

View a list of Star Wars movies

Dynamic content loaded using Fetch API

🛠 Technologies Used

HTML

CSS

JavaScript

Fetch API

Star Wars API (SWAPI)

API used in this project:
https://swapi.dev/

💻 How It Works

The page loads the HTML structure.

JavaScript uses the Fetch API to request data from the Star Wars API.

The returned JSON data is processed.

JavaScript dynamically creates elements and displays them on the page.

Clicking a character opens a collapsible card showing additional information.
